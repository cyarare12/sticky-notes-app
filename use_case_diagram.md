# Sticky Notes Application - Use Case Diagram

## Actors
- User

## Use Cases
1. **Create Note**
   - User provides title and content
   - System saves the note

2. **View Notes**
   - User requests list of notes
   - System displays all notes

3. **Edit Note**
   - User selects a note to edit
   - User modifies title and content
   - System updates the note

4. **Delete Note**
   - User selects a note to delete
   - System confirms deletion
   - System removes the note
